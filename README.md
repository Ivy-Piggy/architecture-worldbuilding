# 建筑 · 建造世界观
### Architecture as World-building · 建筑题材研究

> 从一本手绘建筑图典出发，把「风格」拆成动画、影视与游戏世界观可以调用的词表。

---

## 这是什么

一个持续生长的私人研究库。目标不是复述建筑史，而是回答一个问题：

**当观众看见那根柱子的那一秒，他的心里被安排了什么？**

- **五期门类** — 古代和古典 / 中世纪和文艺复兴 / 巴洛克和新艺术 / 现当代 / 设计元素
- **十二类设计元素** — 穹顶、立柱、塔楼、拱券、拱廊、入口和门道、窗户、山花、山墙、屋顶、拱顶、楼梯（每类附「它在世界观里负责什么」）
- **案例库** — 第一辑：两河、波斯与埃及 15 条（特色 + 世界观用法）
- **四种转译读法** — 时间戳 / 权力量具 / 信仰与仪式 / 技术与材料

## 体例约定

每条案例固定四栏，便于横向比较：

1. **名称 / 地点 / 年代** —— 客观信息，以原书为准
2. **特色** —— 结构、材料、装饰的可观察特征
3. **世界观用法** —— 个人解读，用于动画/影视/游戏设定（非原书观点）
4. **待核标记** —— 年代或信息存疑时显式标出，不隐藏
